🌴 Natours – Tour Booking Backend

A backend API for tour booking with Node.js, MongoDB, Stripe, Pug, and Email Confirmation ✉️.

📖 Description

Natours is a backend application for booking tours.

✨ Features at a glance:

Browse tours & book them 🏖️

Pay securely via Stripe 💳

Admin dashboard to manage tours & bookings 📊

Dynamic pages rendered with Pug 🖥️

Email confirmation on signup to verify users ✉️✅

🛠 Technologies Used

Node.js 🟢

Express.js ⚡

MongoDB & Mongoose 🍃

Stripe API 💳

JWT Authentication 🔒

Pug (for server-side rendering) 🖥️

Nodemailer (for signup confirmation emails) ✉️

dotenv 🌐

🚀 Features

✅ User authentication (signup & login)

✅ Email confirmation on signup

✅ Role-based access control (admin & user)

✅ CRUD operations for tours

✅ Booking system with Stripe payments

✅ Protected routes using JWT

✅ Dynamic pages rendered with Pug

✅ Display tours, bookings, and dashboards in HTML
